# Atividades de Estatística em R

Este repositório reúne minhas atividades do curso de Estatística em R da Universidade Federal Fluminense (UFF).

## Objetivo

Registrar exercícios, análises e scripts desenvolvidos durante a disciplina, com foco em conceitos de estatística aplicados com a linguagem R.

## Conteúdo

- Exercícios práticos em R
- Análise de dados
- Construção de gráficos e tabelas
- Estudo de frequência, distribuição e estatísticas descritivas

## Organização

- `atividade_2.r` — script da atividade em desenvolvimento
- `dados_turismo.csv` — conjunto de dados utilizado nas atividades

## Observação

Este material representa o trabalho realizado ao longo do curso de Estatística em R da UFF e serve como registro de aprendizado.
